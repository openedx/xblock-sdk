## Development setup

To begin development setup, install [uv] and [pnpm], then run:

```bash
make install_prereqs
```

To install this XBlock and begin using it within the tutor environment, generate the frontend code:

```bash
make build
```

Then, add it as a tutor mount. From the parent directory:

```bash
tutor mounts add xblock-{{cookiecutter.short_name}}
tutor images build openedx-dev
```

Then, start [Tutor](https://docs.tutor.edly.io/)'s dev mode or else [launch](https://docs.tutor.edly.io/reference/cli/dev.html#tutor-dev-launch) it if you haven't previously. More information can be found [in the Tutor documentation](https://docs.tutor.edly.io/).

To automatically watch for and rebuild the block's frontend components, run:

```bash
make build.watch
```

Note that build artifacts **must** be committed to the repository in order for this package to be installed as a standard Python package from a git remote source. It is possible to avoid this if using CI to build the relevant assets only upon release and publication to PyPi or another Python repository, however, for widest compatibility, this is not included.
